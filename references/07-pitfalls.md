# 07 · 坑清单

> **按症状索引，不按模块索引。** 出问题时先在这里搜现象，不要从头读文档。
> 每条给「症状 → 原因 → 处置」，需要细节的指向对应分册。

## 二、几条需要展开的坑

### 2.1 同步调用外部进程会失败（Windows）

调用 `VoipEngine.dll` 做 wxgf 解码时，若用**同步**方式启动外部进程，
在 Windows 上会报 EBUSY，而且异常容易被静默吞掉——
现象是「解码看起来成功，实际一张都没出来」，排查很久才发现根因。

**规则：凡是要启动外部进程的地方，一律用异步方式，并且把子进程的输出落盘到日志文件。**
输出被丢弃时会失去唯一的线索。

### 2.2 三层缓存，各修各的

「明明改对了，看到的还是旧的」有三种成因，逐层排查：

| 层 | 表现 | 处置 |
|---|---|---|
| 浏览器 HTTP 缓存 | 重新构建后页面还是旧的 | 媒体与静态资源 URL 带版本号 |
| 应用层解码缓存 | 换了密钥 / 改了算法，结果不变 | **建议做法**：缓存按源文件 mtime 失效，或加版本号重算（参考实现里没有 mtime 机制） |
| 微信本地文件 | 用户在微信点开了原图，这边还是缩略图 | 缩略图响应设 `no-cache`，刷新即可 |

三层的排查顺序：先看资源 URL 有没有版本号，再看服务端缓存目录，最后看微信本地是否真有原图。

### 2.3 分页用 offset 会错位

增量同步往库里插入新消息后，按 `OFFSET` 翻页会出现**重复条目或整段漏读**。
改用时间戳游标即可免疫。

这条的隐蔽之处：本地测试时数据不变，翻页永远正常；一上线接真实增量就出问题。

### 2.4 两种转义规则共存，容易写反

同一条消息的 XML 里有两套规则，方向相反：

- `<title>` 等普通字段：**要做 HTML 实体解码**（空格可能写成 `&#x20;`）；
- `<![CDATA[...]]>` 包裹的内容：**按原样取，不做实体转义**。

写反的后果分别是文件名对不上（404）和内容被二次转义。看到「文件名看着对但就是找不到」
先查这条。

### 2.5 `xorSize` 字段不可信

图片容器头里的该字段在大文件上固定写成 1048576（1MB），与实际不符。
按它截断会导致大图全部解不出来，而小图正常——现象很迷惑。

正确做法：XOR 区解到文件末尾，再裁掉尾部元数据。

### 2.6 缩略图无法还原成高清

缩略图约 210×157，像素信息不足，放大属于猜测。
原图只有在微信客户端点开过才会下载到本机，且**缓存按设备独立**——
手机端点开不会让电脑端拿到原图。这条要主动向用户说明，否则会被当成程序缺陷。

## 三、环境与平台坑

### 3.1 Python 依赖

缺 `zstandard` 时，压缩内容会变成乱码，而且不会报错。
缺 `pycryptodome` 时，AES 相关步骤直接失败。

装之前先确认共享环境里是否已有，避免重复安装。

### 3.2 Windows 启动脚本的坑（`.bat`）

这一组坑一旦踩上，症状很吓人且不容易联想到根因，单独列出：

| 坑 | 症状 | 处置 |
|---|---|---|
| **`.bat` 存成 UTF-8 或 LF 换行** | 控制台刷出一片「`xx` 不是内部或外部命令」，**但脚本后半段被静默跳过**——看着像命令写错了，实际是编码问题 | 必须 **GBK(936) + CRLF**。改动时别直接写文件：先用 UTF-8 写一份临时源文件，再用脚本转码覆盖 |
| 用 `timeout /t n` 做等待 | stdin 被重定向的场合直接报「不支持输入重新定向」并退出 | 改用 `start /min` + 自轮询，或写 `%SystemRoot%\System32\...` 全路径 |
| 裸写 `node` / `npm` / `timeout` 等命令名 | Git Bash 等环境里的同名程序会抢先命中（PATH 顺序），行为与 Windows 版不同 | 一律写**全路径** |

**第一条为什么这么坑**：cmd 的批处理解析器按**字节偏移**定位命令。
遇到多字节中文 + `if (...)` 括号块时会错位串行，把一行拆成几段当命令执行——
于是报出一堆残缺 token，同时**整段逻辑被跳过**，程序行为与预期完全不同。

### 3.3 超长路径

深层嵌套目录（异常中断、递归复制留下的）会超出路径长度限制。
某些执行环境**不接受超过约 260 字符的路径**，连 `\\?\` 前缀也无效。

清理办法是「路径提升」：递归时一旦子路径超过阈值（约 150 字符），
用重命名把该子目录整体搬到短的根目录（如 `D:\_tmp_del\tN`），再从短路径继续下潜。

自己写遍历、备份、打包逻辑时，要**排除数据目录**，否则可能递归复制自己。

### 3.4 后台任务被回收

后台启动的服务进程可能随命令结束被清理，表现是请求报 502。
启动与验证要放在同一条命令里完成，或改用真正的后台任务方式。

### 3.5 代理劫持本地回环

若本机设了 HTTP 代理，访问 `127.0.0.1` 的请求可能被代理接管并返回 502。
验证本地接口时显式绕过代理（例如 curl 加 `--noproxy '*'`）。

### 3.6 界面改动不生效

前端源码改完**必须重新构建**，因为服务托管的是构建产物。
忘了构建会让人误以为是逻辑问题，白查很久。
